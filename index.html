Before you order

  1. Check the original listing. Confirm the seller URL, color, size and price. If you plan to order through HooBuy, check whether HooBuy accepts the original seller URL.
  2. Compare measurements. Use the seller’s chart and measure a similar garment you own. For shoes, check whether the chart uses foot length or insole length.
  3. Review warehouse QC photos. If photos are available for your order, check the size tag, seams, color and any requested measurements. Review the return window before approving shipment.
  4. Estimate the delivered total. Add the item price, domestic freight, agent fees, international shipping and applicable taxes. Check whether the shipping quote uses actual or volumetric weight.

HooBuy spreadsheet FAQ

What is a HooBuy spreadsheet?

A shopping spreadsheet is a shortlist of product finds. It usually records an item name, seller link, category and reference price so you can compare options before buying.

Where do these listings come from?

The products shown here come from HipobuyFind. The item links open the corresponding HipobuyFind listing.

Do the prices include delivery?

The prices shown are listing prices in Chinese yuan. Get a destination-specific shipping quote and check fees and taxes before ordering.
